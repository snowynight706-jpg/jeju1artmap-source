## 실기기에서만 남는 확인

설정 동시성 모듈은 가짜 D1에서 두 저장 요청을 실제로 겹쳐 실행하는 행위 테스트를 추가했다. 한 요청만 revision 1로 완료되고 다른 요청은 409를 받는 경로, stale revision에 최신 revision을 반환하는 경로, 쓰기 실패 뒤 잠금이 해제되는 경로까지 4개 테스트가 통과했다. 아래 항목은 운영 인증·실제 OS 이벤트가 필요한 최종 확인이다.

- 인증된 관리자 세션 두 개에서 같은 설정과 같은 장소 승인 요청을 동시에 저장해 한쪽의 409와 최신 revision 재로딩 확인
- 실제 모바일 OS 앱 전환·화면 회전 중 `pointercancel`을 유도해 마지막 손가락 해제 뒤 라벨 정지 클래스가 남지 않는지 확인
- 새 저사양 독립 실행 PWA 표본이 쌓인 뒤 위 기준선과 중앙값·200ms 이상 비율 비교
