# v20 출력 지도 자산 최적화 기록

## 기준

- 현재 공개 배치가 사용하는 `제주원도심_랜드마크탐색_베이스맵_v20.png`를 기준으로 한다.
- 지도 범위, 8,944×7,324 해상도, 색상과 모든 픽셀을 변경하지 않는다.
- 화면 탐색은 기존 2048·4096 WebP를 유지하고, 고화질 내보내기 때만 출력 원본을 불러온다.
- 사용자가 받는 8,944px·12,000px 결과 파일은 인쇄 호환성을 위해 기존 PNG를 유지한다.

## 비교

| 후보 | 용량 | 원본 대비 | 디코딩된 RGBA SHA-256 | 판단 |
|---|---:|---:|---|---|
| 현행 v20 PNG | 7,012,151B | 기준 | `d509c3fc9a824ea0af4f4ee5971cec2036415f7ae188d37d69c930e69693bcff` | 보존 원본 |
| 최적화 PNG | 6,354,840B | 약 9% 감소 | 원본과 동일 | 감소 폭이 작아 미채택 |
| 무손실 WebP | 1,959,996B | 약 72% 감소 | 원본과 동일 | 출력 합성 원본으로 채택 |

세 파일을 각각 RGBA 262,023,424바이트로 디코딩한 뒤 전체 바이트의 SHA-256을 비교했다. 세 결과가 모두 같아 WebP 변환에 따른 색상·경계·좌표 변화가 없다.

## 적용 방식

- `public/maps/wondosim-base-map-v20-print-lossless.webp`를 출력 전용 자산으로 둔다.
- 현재 v20 업로드 버전과 일치할 때 `/api/base-map?bundled=original&v=...`의 불변 캐시 경로를 반환한다.
- 새 베이스맵이 관리자 화면에서 업로드되면 고정 v20 자산을 사용하지 않고 새 R2 원본과 파생본으로 자동 전환한다.
- 일반 지도 이동·확대에는 이 8,944px 파일을 사용하지 않으므로 초기 화면과 제스처 성능에는 영향을 주지 않는다.

무손실 WebP의 디코딩 메모리는 PNG와 같은 약 250MiB다. 이번 변경은 출력 시 네트워크 전송량을 줄이는 것이며, 12K 캔버스 합성 자체의 메모리 사용량을 줄이는 변경은 아니다.
