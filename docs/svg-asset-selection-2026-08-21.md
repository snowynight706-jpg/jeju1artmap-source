# WebP → SVG 자산 선별 및 적용 기록

## 적용 결론

현행 화면에서 SVG 전환 이득이 있고 기존 디자인을 안전하게 보존할 수 있는 항목은 재단 CI 2종뿐이다.

| 자산 | 결정 | 근거 |
|---|---|---|
| 재단 국문 시그니처 B | SVG 적용 | 공식 AI에 글자 윤곽과 심벌 곡선이 포함되어 확대 품질과 압축 효율을 함께 확보할 수 있음 |
| 재단 헤더 심벌 | SVG 적용 | 공식 AI의 곡선 경로를 사용하고 기존 화면의 밝은 9색 팔레트를 그대로 유지할 수 있음 |
| 공개 카테고리 UI 5종 | WebP 유지 | 승인본이 음영·반사·질감이 있는 96px 일러스트이며 기존 단순 SVG는 외형이 다름 |
| 랜드마크 54종 | WebP 유지 | 회화적 음영과 세부 묘사가 많아 자동 추적 시 경로 수·페인트 비용·왜곡이 증가함 |
| v20 베이스맵 | WebP 유지 | 현행 v20과 동일한 벡터 마스터가 없고, v15 SVG는 지도 내용과 버전이 다름 |
| 범용 마커 | 기존 SVG 유지 | 이미 작은 순수 SVG로 제공됨 |
| PWA 설치 아이콘 | PNG 유지 | manifest·마스커블 아이콘 호환을 위한 설치 자산임 |

## 공식 원본과 생성 방식

- 공식 안내: [제주문화예술재단 CI](https://www.jfac.kr/IntroductionFoundation/jfacIntroduction/jfacFoundationCI)
- 공식 배포 원본: `CI_AI.zip`의 `CI_BS06_국문 시그니처 B.ai`
- 공식 배포 원본: `심볼마크_AI.zip`의 `CI_BS01_심볼마크.ai`
- 두 AI 파일의 컬러 페이지를 Inkscape로 SVG 변환한 뒤 `scripts/extract-jfac-svg-assets.mjs`로 실제 CI 경로만 추출했다.
- 자동 비트맵 추적, 이미지 임베딩, 폰트 의존 텍스트는 사용하지 않았다.
- 로딩 시그니처는 공식 컬러 페이지의 곡선·색상을 그대로 사용한다.
- 헤더 심벌은 공식 곡선 geometry를 사용하되 현행 헤더의 밝은 승인 팔레트 9색을 유지한다.

## 전송 크기

SVG는 텍스트 응답 압축이 적용되므로 gzip 레벨 9를 보수적인 비교 기준으로 사용했다.

| 자산 | 기존 WebP | SVG 원본 | SVG gzip | 기존 대비 gzip 절감 |
|---|---:|---:|---:|---:|
| 국문 시그니처 B | 17,680B | 32,257B | 10,507B | 40.6% |
| 헤더 심벌 | 31,080B | 5,099B | 2,500B | 92.0% |
| 합계 | 48,760B | 37,356B | 13,007B | 73.3% |

시그니처 SVG 원본은 WebP보다 크지만 서버 압축 후에는 더 작다. 두 자산은 `?v=20260821-svg1` revision과 1년 immutable 캐시를 사용하고, 모바일·PC·설치형 PWA 모두 같은 SVG를 최초부터 사용하므로 해상도 전환이나 추가 디코딩 단계가 없다.

## 시각 검증

- `jfac-signature-b.svg`를 기존 1182×626 크기로 래스터화해 공식 PNG와 겹쳐 확인했다. 색상과 곡선은 동일하며 렌더러별 경계 안티앨리어싱 차이만 남는다.
- `jfac-symbol.svg`는 기존 446×140 화면 비율로 렌더링하고 기존 헤더의 9색을 직접 보존했다. 실제 화면 표시 폭은 PC 46px, 모바일 40px이므로 경계 샘플링 차이는 시각적으로 구분되지 않는다.
- SVG 내부에는 `<image>`나 `data:image`가 없고 모든 글자·심벌은 path다.
